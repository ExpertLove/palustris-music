# 🎧 Музыка — music.palustris.ru

**Веб-плеер и Android-приложение поверх каталога YouTube Music.**
«Моя волна», тексты песен, эквалайзер, плейлисты с публичными ссылками, офлайн в приложении.

[Сайт](https://music.palustris.ru) · [Архитектура](docs/ARCHITECTURE.md) · [Сервер](docs/SERVER.md) · [Разработка](docs/DEVELOPMENT.md) · [YouTube и блокировки](docs/YOUTUBE.md) · [История и планы](docs/HISTORY.md)

## Что это

| Часть | Стек | Где живёт |
|---|---|---|
| **Бэкенд** `server/` | Rust · axum 0.8 · SQLite (rusqlite) · yt-dlp | `/opt/music` на сервере, сервис `music.service` |
| **Сайт** `web/` | React 19 · TypeScript · Vite · zustand · Web Audio | статика `/opt/music/web`, отдаёт Caddy |
| **Приложение** `android/` | Kotlin · Jetpack Compose (M3 Expressive) · Media3 · Hilt · Retrofit · Glance | APK, раздаётся файлом; CI собирает отладочный APK |
| **Инфраструктура** `ops/` | Caddy · systemd · cron · Docker (PO-токены) | Ubuntu 26.04, `music.palustris.ru` |

Музыку сервер берёт из YouTube через **yt-dlp**, метаданные — из внутреннего API YouTube Music, тексты — из LRCLIB.
Если YouTube трек не отдал, сервер ищет ту же запись исполнителя в Яндекс Музыке, Audius, SoundCloud и archive.org
и честно это показывает («Версия с Яндекс Музыкой», «Версия с SoundCloud»). Своих треков у сервиса нет.

## Возможности

- **Плеер:** эквалайзер на 10 полос с пресетами, ровная громкость, плавные переходы до 12 с, скорость, очередь
  с перетаскиванием, перемешивание и повтор, таймер сна, полноэкранный режим с визуализатором, тексты с подсветкой строк,
  управление с экрана блокировки и наушников, горячие клавиши (`?`).
- **Каталог:** поиск по трекам, исполнителям, альбомам и плейлистам; страницы исполнителей и альбомов; чарты по странам; настроения.
- **Для тебя:** «Моя волна» и «Для вас» на радио YouTube Music от того, что ты дослушал и лайкнул; учитываются
  пропуски, «не нравится» и скрытые исполнители. Настройки волны (любимое, незнакомое, популярное; настроение и
  занятие), радио по треку и исполнителю, миксы дня, «Забытое любимое», «На повторе», статистика и итоги года
  (сторис с картинкой для «Поделиться») — на сайте и в приложении. «Не нравится» — в меню трека, рядом с лайком
  в плеере, когда играет подборка, и клавишей `D`; всё скрытое можно вернуть в разделе «Скрытое».
- **Библиотека:** лайки, плейлисты (переименование, порядок, обложка-коллаж, публичная ссылка), история.
- **Дизайн «Обложка задаёт цвет»:** интерфейс перекрашивается под играющий трек; плеер — стеклянная панель; PWA.
- **Скорость:** трек начинает играть через ~2 с — сервер отдаёт файл, пока yt-dlp его ещё качает; следующие треки подгружаются заранее.
- **Аккаунты:** cookie-сессии на 60 дней, выход везде, смена и сброс пароля по почте.
- **Админка `/admin`:** аккаунты YouTube для обхода блокировок, журнал загрузок, логи сервера, пользователи.
- **Android:** всё, что умеет плеер на сайте (скорость, очередь с перетаскиванием, исполнители и история в
  «Моей музыке», жанры при регистрации), плюс фоновое воспроизведение, скачивание треков в компактном Opus,
  лайки и плейлисты без интернета (изменения уходят на сервер, когда появится связь), ссылки на плейлисты
  (открываются сразу в приложении), виджет на главный экран, Android Auto. Плеер ездит за пальцем, обложка
  смахивается и пульсирует в такт, живой фон и спектр; «Итоги года» сторис с «Поделиться». Админка и горячие
  клавиши остаются на сайте.

## Быстрый старт

```bash
git clone https://github.com/ExpertLove/palustris-music.git && cd palustris-music

# сайт: http://localhost:5173, /api проксируется на прод
cd web && npm ci && npm run dev

# бэкенд: проверка и тесты (локально запускать не обязательно)
cd server && cargo test
```

Подробнее, включая локальный запуск бэкенда и Android, — в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Выкладка

```bash
./ops/deploy-web.sh next      # сайт на проверочный адрес https://music.palustris.ru/next/
./ops/deploy-web.sh prod      # сайт в корень
./ops/deploy-server.sh        # бэкенд: исходники на сервер → сборка там → перезапуск
```

Нужен SSH-ключ администратора сервера (`~/.ssh/palustris_admin`, в репозитории его нет).
Перед каждой выкладкой текущая версия копируется в `/root/backups/`. Откат — в [docs/SERVER.md](docs/SERVER.md#откат).

## Структура

```
server/          бэкенд (Rust)
  src/main.rs      API, сессии, пароли, плейлисты, история
  src/audio.rs     yt-dlp → кэш, отдача трека во время загрузки, предзагрузка, очистка кэша, блок YouTube
  src/sources.rs   запасные источники звука: Audius, SoundCloud, archive.org
  src/yandex.rs    Яндекс Музыка: поиск и звук по токену аккаунта, расшифровка AES-CTR
  src/accounts.rs  аккаунты YouTube: ротация, паузы, журнал загрузок
  src/admin.rs     API админки
  src/yt.rs        YouTube Music: поиск, исполнители, альбомы, чарты
  src/recs.rs      «Моя волна» и рекомендации
  src/lyrics.rs    тексты из LRCLIB
  src/compact.rs   компактные Opus-копии для приложения
  src/mail.rs      письма (подтверждение, сброс пароля)
  src/db.rs        схема SQLite и миграции
web/             сайт (React)
  src/player/      аудиодвижок (Web Audio), очередь, Media Session
  src/pages/       экраны, включая Admin.tsx
  src/components/  плеер, списки, меню, эквалайзер
android/         приложение — см. android/AGENTS.md и android/docs/API.md
ops/             Caddy, systemd, cron, скрипты выкладки и обслуживания
docs/            документация
```

## Важно

- **Юридически.** Сервис раздаёт аудио с YouTube. Это нарушает условия YouTube; публичная раздача такого клиента — риск.
  Код открыт для чтения, но **лицензии нет — все права у владельца**: копировать и разворачивать свои копии сервиса нельзя.
- **Репозиторий публичный.** Секретов в нём нет и быть не должно: ни SSH-ключа, ни паролей, ни cookies, ни ключа подписи APK,
  ни почт админов. Где они — в [docs/SERVER.md](docs/SERVER.md#секреты). Правила — в [SECURITY.md](SECURITY.md).
