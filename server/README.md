# Музыка

Веб-плеер с поиском по YouTube Music, аккаунтами, лайками, плейлистами и своими рекомендациями.

## Стек

- **backend** — Rust + axum + SQLite (`src/`)
- **frontend** — React + TypeScript + Vite (`web/`)
- **аудио** — `yt-dlp` качает m4a в кэш, отдаётся с поддержкой Range

## Локальный запуск

```bash
# зависимости
cd web && bun install
sudo pacman -S yt-dlp   # или скачать бинарник

# backend
cargo run            # 127.0.0.1:8030

# frontend (второй терминал)
cd web && bun run dev  # 127.0.0.1:5173, /api проксируется на 8030
```

Переменные окружения: `MUSIC_DATA`, `MUSIC_CACHE`, `MUSIC_WEB`, `MUSIC_ADDR`, `MUSIC_YTDLP`.

## Деплой

`./deploy.sh` — соберёт фронт, зальёт на VPS, пересоберёт бэкенд, перезапустит systemd.

Прод: `https://palustris.ru/music/` (Caddy → 127.0.0.1:8030).

## API

| Метод | Путь | Что |
|---|---|---|
| POST | `/api/register` | `{email,password}` → `{token}` |
| POST | `/api/login` | то же |
| GET | `/api/search?q=` | поиск по YouTube Music |
| GET | `/api/stream/{id}` | аудио (Range, кэш) |
| GET/POST | `/api/likes` | лайки |
| GET/POST | `/api/playlists` | плейлисты |
| POST | `/api/history` | запись прослушивания |
| GET | `/api/recs` | подборка |

## Рекомендации (v1)

Профиль вкуса = лайки (вес 3) + история с затуханием (полураспад 21 день), агрегируется по артистам.
Берутся топ-6 артистов, для каждого ищутся треки, отсеиваются сыгранные за 3 дня и лайкнутые,
остаток сортируется по силе вкуса к артисту + случайный шум для исследования.

Дальше: item2vec по сессиям, акустические признаки (`bliss-audio`), MMR для разнообразия, онлайн-логистическая регрессия на скипах.

## Дорожная карта

1. Веб (сейчас): YouTube Music, аккаунты, синхронизация, рекомендации v1.
2. Яндекс Музыка как второй источник (неофициальный API, нужен токен).
3. Десктоп: Tauri 2, локальные файлы + librespot (нужен Spotify Premium).
4. Мобилка: Tauri 2 mobile + foreground service.

## Юридическое

YouTube/Яндекс-источники — неофициальные, на свой аккаунт и свой сервер. Публично распространять такой клиент нельзя.
